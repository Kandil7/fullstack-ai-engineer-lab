## Level Definitions

| Level | Description |
|-------|-------------|
| 1 | Aware — know what it is, no hands-on |
| 2 | Exposure — completed tutorials, basic usage |
| 3 | Basic — can use with documentation |
| 4 | Working — can build simple things independently |
| 5 | Working+ — can build moderate features, debug issues |
| 6 | Intermediate — can architect solutions, handle edge cases |
| 7 | Advanced — can teach others, optimize, design patterns |
| 8 | Expert — production-grade mastery, performance tuning |
| 9 | Specialist — deep expertise, contributes to ecosystem |
| 10 | Authority — recognized expert, shapes best practices |

## Skills by Phase

### Phase 0 (Months 1–3): Foundations
- **Focus:** Go basics, Git mastery, HTML/CSS/JS fundamentals
- **Target upgrades:** Go 1→4, Git 3→5, HTML/CSS/JS 1→5

### Phase 1+2 (Months 4–6): Backend + Frontend
- **Focus:** Go backend, PostgreSQL, Redis, Flutter or Next.js
- **Target upgrades:** Go 4→6, PostgreSQL 1→5, Redis 1→5, Flutter/Next.js 1→5

### Phase 3 (Months 7–9): AI Fundamentals
- **Focus:** Python, ML basics, prompt engineering
- **Target upgrades:** Python 2→5, ML 1→5, Prompt Eng 2→6

### Phase 4 (Months 10–11): RAG Systems
- **Focus:** Embeddings, vector search, RAG pipeline
- **Target upgrades:** RAG 1→7, Python 5→6

### Phase 5 (Month 12): AI Agents
- **Focus:** Tool calling, multi-agent orchestration
- **Target upgrades:** Agents 1→5, Prompt Eng 6→7

### Phase 6 (Months 8–12): System Design + DevOps
- **Focus:** Architecture, Docker, CI/CD
- **Target upgrades:** Docker 1→5, System Design 2→6
