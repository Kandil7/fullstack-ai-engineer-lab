## Why these were archived rather than deleted

Four overlapping plans were live simultaneously, contradicting each other on timeline,
ordering, technology, and target role. Every planning session began by re-deciding which one
applied. Archiving them makes the active plan unambiguous while preserving the reasoning trail
— and the raw export in particular is the provenance for everything in `docs/reference/`.

## Known artifacts in the raw export

`Python-essentials-for-AI-engineers.md` is a machine-generated chat export and contains
transcription noise — `iiwm` at line 822, `kدة` at line 860, and an "AI Exporter" footer. The
extracted reference documents are cleaned; the export is not.
