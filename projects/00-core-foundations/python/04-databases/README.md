# 🗄️ Phase 4: Database Integration

23 exercise files covering both SQL (MySQL) and NoSQL (MongoDB) databases.

| Module | Files | Approach |
|--------|-------|----------|
| **MySQL** | 12 | Uses Python's built-in `sqlite3` as a stand-in (SQL syntax is nearly identical) |
| **MongoDB** | 11 | Uses Python dicts as stand-in documents (mirrors MongoDB query syntax) |

## Quick Start

```bash
# MySQL exercises (no external deps needed)
python mysql/01-getting-started.py

# MongoDB exercises (no external deps needed)
python mongodb/01-getting-started.py
```
