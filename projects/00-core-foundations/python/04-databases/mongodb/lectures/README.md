# MongoDB Lectures

| # | Topic | Description |
|---|-------|-------------|
| 01 | Getting Started | NoSQL, documents, collections, PyMongo |

| 03 | Collections | Creating, listing, capped collections |
| 04 | Insert | insert_one, insert_many, _id |
| 05 | Find | find, find_one, projection |
| 06 | Query | Query operators, $gt, $lt, $regex |
| 07 | Sort | Sorting ascending/descending |
| 08 | Limit | limit, skip, pagination |
| 09 | Delete | delete_one, delete_many |
| 10 | Update | update_one, update_many, $set |
| 11 | Aggregation | Pipeline, $match, $group |
