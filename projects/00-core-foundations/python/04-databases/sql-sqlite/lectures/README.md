# MySQL Lectures

## Overview

12 lectures covering MySQL database operations with Python, from getting started to advanced queries.

## Topics

| # | Topic | Description |
|---|-------|-------------|
| 01 | Getting Started | MySQL connector, connections, cursors |
| 02 | Create Database | CREATE, USE, DROP database |
| 03 | Create Table | CREATE TABLE, data types, constraints |
| 04 | Insert | INSERT, parameterized queries |
| 05 | Select | SELECT, DISTINCT, aliases, LIMIT |
| 06 | Where | WHERE, operators, AND/OR/NOT |
| 07 | Order By | Sorting, ASC/DESC, multiple columns |
| 08 | Delete | DELETE, TRUNCATE, soft delete |
| 09 | Update | UPDATE, SET, conditional updates |
| 10 | Drop Table | DROP, TRUNCATE vs DELETE |
| 11 | Join | INNER, LEFT, RIGHT, SELF joins |
| 12 | Union | UNION, UNION ALL, INTERSECT |
