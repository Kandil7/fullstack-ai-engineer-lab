# Advanced Python Lecture 06: Dataclasses

## Topic Overview

Dataclasses (introduced in Python 3.7 via PEP 557) provide a decorator and function for automatically generating special methods like `__init__`, `__repr__`, `__eq__`, and more based on class annotations. They reduce boilerplate code significantly, making them ideal for data-carrying classes, configuration objects, API models, and anywhere you need clean, maintainable data structures.

## 1. Basic Dataclasses

### The Problem Dataclasses Solve

```python
# Without dataclasses - lots of boilerplate
class PointRegular:
    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y
    
    def __repr__(self) -> str:
        return f"PointRegular(x={self.x}, y={self.y})"
    
    def __eq__(self, other) -> bool:
        if not isinstance(other, PointRegular):
            return False
        return self.x == other.x and self.y == other.y

# With dataclasses - one decorator does it all
from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float

# Automatically generates:
# __init__, __repr__, __eq__, and more
p1 = Point(3.0, 4.0)
p2 = Point(3.0, 4.0)
print(p1)           # Point(x=3.0, y=4.0)
print(p1 == p2)     # True
```

### Generated Special Methods

```python
from dataclasses import dataclass

@dataclass
class User:
    name: str
    age: int
    email: str

user = User("Alice", 30, "alice@example.com")

# __init__ - generated
print(user.name)  # "Alice"

# __repr__ - generated
print(repr(user))  # User(name='Alice', age=30, email='alice@example.com')

# __eq__ - generated
user2 = User("Alice", 30, "alice@example.com")
print(user == user2)  # True

# __hash__ - NOT generated by default (mutable)
# print(hash(user))  # TypeError

# __slots__ - NOT generated by default
# __setattr__, __getattribute__ - default behavior
```

## 2. Controlling Generated Methods

```python
from dataclasses import dataclass

# Disable specific methods
@dataclass(repr=False, eq=False, frozen=True)
class Config:
    host: str = "localhost"
    port: int = 8080

config = Config()
# print(repr(config))  # AttributeError - repr disabled
# config.host = "new"  # AttributeError - frozen

# Or selectively disable
@dataclass(eq=False)
class NoEquality:
    value: int
    
    def __eq__(self, other):
        """Custom equality check."""
        return self.value > other.value
```

### The `order` Parameter

```python
from dataclasses import dataclass

@dataclass(order=True)
class Score:
    name: str
    points: int

# Generates __lt__, __le__, __gt__, __ge__
s1 = Score("Alice", 95)
s2 = Score("Bob", 87)

print(s1 > s2)   # True (compares by fields in order)
print(s1 >= s2)  # True
print(s1 < s2)   # False
```

## 3. The `field()` Function

```python
from dataclasses import dataclass, field

@dataclass
class User:
    name: str
    age: int
    email: str
    tags: list[str] = field(default_factory=list)
    score: float = field(default=0.0)
    _id: int = field(init=False, repr=False)

# field() options:
# - default: Default value
# - default_factory: Factory function for mutable defaults
# - repr: Include in __repr__
# - init: Include in __init__
# - compare: Include in __eq__ and __hash__
# - hash: Include in hash calculation
# - metadata: Arbitrary mapping
```

### Default Factory

```python
from dataclasses import dataclass, field
from typing import Any

@dataclass
class DataProcessor:
    name: str
    config: dict[str, Any] = field(default_factory=dict)
    history: list[str] = field(default_factory=list)
    cache: set[str] = field(default_factory=set)

# Each instance gets its own copy
p1 = DataProcessor("p1")
p2 = DataProcessor("p2")
p1.config["key"] = "value"
print(p2.config)  # {} - separate instance
```

### Field Metadata

```python
from dataclasses import dataclass, field

@dataclass
class APIEndpoint:
    path: str = field(metadata={"description": "API path", "required": True})
    method: str = field(metadata={"description": "HTTP method", "default": "GET"})
    auth_required: bool = field(metadata={"description": "Requires authentication"})

# Access metadata
for f in field(APIEndpoint):
    if f.metadata:
        print(f.name, f.metadata)
```

## 4. Frozen Dataclasses (Immutable)

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Point:
    x: float
    y: float

p = Point(3.0, 4.0)
# p.x = 5.0  # AttributeError: cannot assign to field

# Now hashable - can be used in sets and as dict keys
point_set = {p}
point_dict = {p: "origin"}

# Can be used in another frozen dataclass
@dataclass(frozen=True)
class Line:
    start: Point
    end: Point

line = Line(Point(0, 0), Point(1, 1))
```

### Frozen with Custom `__hash__`

```python
from dataclasses import dataclass, field

@dataclass(frozen=True, eq=True)
class Vertex:
    x: float
    y: float
    label: str = field(hash=False, compare=False)

v1 = Vertex(1.0, 2.0, "A")
v2 = Vertex(1.0, 2.0, "B")
print(v1 == v2)  # True (label excluded from comparison)
print(hash(v1) == hash(v2))  # True (label excluded from hash)
```

## 5. `__post_init__` for Validation

```python
from dataclasses import dataclass, field

@dataclass
class Temperature:
    celsius: float
    
    def __post_init__(self):
        if self.celsius < -273.15:
            raise ValueError("Temperature below absolute zero")
    
    @property
    def fahrenheit(self) -> float:
        return self.celsius * 9/5 + 32

# Usage
temp = Temperature(100.0)
print(temp.fahrenheit)  # 212.0

# Validation on creation
try:
    temp = Temperature(-300.0)  # ValueError
except ValueError as e:
    print(e)  # "Temperature below absolute zero"
```

### Complex Validation

```python
from dataclasses import dataclass, field
from typing import Any

@dataclass
class UserRegistration:
    username: str
    email: str
    password: str
    confirm_password: str
    age: int
    
    def __post_init__(self):
        # Validate username
        if not self.username.isalnum():
            raise ValueError("Username must be alphanumeric")
        if len(self.username) < 3:
            raise ValueError("Username must be at least 3 characters")
        
        # Validate email
        if "@" not in self.email:
            raise ValueError("Invalid email address")
        
        # Validate password match
        if self.password != self.confirm_password:
            raise ValueError("Passwords do not match")
        
        # Validate age
        if self.age < 13:
            raise ValueError("Must be at least 13 years old")
        
        # Derived values
        self.username = self.username.lower()
        self.email = self.email.lower()

# Usage
user = UserRegistration(
    username="Alice",
    email="Alice@Example.COM",
    password="secret123",
    confirm_password="secret123",
    age=25
)
print(user.username)  # "alice" (normalized)
print(user.email)     # "alice@example.com" (normalized)
```

## 6. Inheritance with Dataclasses

```python
from dataclasses import dataclass, field

@dataclass
class Base:
    name: str
    created_at: str = "2024-01-01"

@dataclass
class Derived(Base):
    value: int
    extra: str = "default"

# Generated __init__ includes all fields
d = Derived(name="test", value=42)
print(d)  # Derived(name='test', created_at='2024-01-01', value=42, extra='default')
```

### Inheritance Issues and Solutions

```python
from dataclasses import dataclass, field

# Problem: Mutable default in parent
@dataclass
class Parent:
    items: list[str] = field(default_factory=list)

@dataclass
class Child(Parent):
    extra: str = "child"

# Solution: Use default_factory
@dataclass
class SafeParent:
    items: list[str] = field(default_factory=list)
    metadata: dict[str, str] = field(default_factory=dict)

@dataclass
class SafeChild(SafeParent):
    extra: str = "child"
    tags: set[str] = field(default_factory=set)

child = SafeChild(items=["a", "b"], extra="custom")
print(child)  # SafeChild(items=['a', 'b'], metadata={}, extra='custom', tags=set())
```

## 7. Conversion Utilities

```python
from dataclasses import dataclass, asdict, astuple, fields

@dataclass
class User:
    name: str
    age: int
    email: str
    scores: list[int] = field(default_factory=list)

user = User("Alice", 30, "alice@example.com", [95, 87, 92])

# Convert to dictionary
user_dict = asdict(user)
print(user_dict)
# {'name': 'Alice', 'age': 30, 'email': 'alice@example.com', 'scores': [95, 87, 92]}

# Convert to tuple
user_tuple = astuple(user)
print(user_tuple)  # ('Alice', 30, 'alice@example.com', [95, 87, 92])

# Access field information
for f in fields(user):
    print(f"{f.name}: {f.type} (default={f.default})")

# JSON serialization
import json
json_str = json.dumps(asdict(user))
```

### Recursive Conversion

```python
from dataclasses import dataclass, asdict
from typing import Any

@dataclass
class Address:
    street: str
    city: str
    country: str

@dataclass
class Company:
    name: str
    address: Address

@dataclass
class Employee:
    name: str
    company: Company

# asdict recursively converts nested dataclasses
emp = Employee(
    name="Alice",
    company=Company(
        name="TechCorp",
        address=Address("123 Main St", "Springfield", "US")
    )
)

print(asdict(emp))
# {'name': 'Alice', 'company': {'name': 'TechCorp', 'address': {'street': '123 Main St', 'city': 'Springfield', 'country': 'US'}}}
```

## 8. Dataclasses vs Alternatives

```python
# Dataclass
@dataclass
class PointDC:
    x: float
    y: float

# NamedTuple (immutable, lighter weight)
from typing import NamedTuple

class PointNT(NamedTuple):
    x: float
    y: float

# Regular dict
point_dict = {"x": 3.0, "y": 4.0}

# Regular class
class PointClass:
    def __init__(self, x: float, y: float):
        self.x = x
        self.y = y
```

### When to Use What

```python
# Use Dataclass when:
# - Need mutable data with auto-generated methods
# - Want validation in __post_init__
# - Need complex default values
@dataclass
class Config:
    host: str
    port: int
    debug: bool = False
    tags: list[str] = field(default_factory=list)
    
    def __post_init__(self):
        if self.port < 1 or self.port > 65535:
            raise ValueError("Invalid port")

# Use NamedTuple when:
# - Need immutable, lightweight tuples
# - Want named fields for readability
# - Memory efficiency matters
from typing import NamedTuple

class Coordinate(NamedTuple):
    latitude: float
    longitude: float

# Use dict when:
# - Schema is dynamic or unknown
# - Quick prototyping
# - JSON-like data structures
```

## 9. Dataclasses in AI Engineering

### Model Configuration

```python
from dataclasses import dataclass, field

@dataclass
class TrainingConfig:
    model_name: str
    learning_rate: float = 0.001
    batch_size: int = 32
    epochs: int = 100
    optimizer: str = "adam"
    weight_decay: float = 0.0
    scheduler: str = "cosine"
    warmup_steps: int = 1000
    
    def __post_init__(self):
        if self.learning_rate <= 0:
            raise ValueError("Learning rate must be positive")
        if self.batch_size <= 0:
            raise ValueError("Batch size must be positive")

@dataclass
class ModelArchitecture:
    input_dim: int
    hidden_dims: list[int] = field(default_factory=lambda: [256, 128])
    output_dim: int = 10
    dropout: float = 0.2
    activation: str = "relu"
    
    def total_parameters(self) -> int:
        # Calculate total parameters
        params = self.input_dim * self.hidden_dims[0]
        for i in range(len(self.hidden_dims) - 1):
            params += self.hidden_dims[i] * self.hidden_dims[i + 1]
        params += self.hidden_dims[-1] * self.output_dim
        return params
```

### Data Pipeline Configuration

```python
from dataclasses import dataclass, field
from typing import Optional

@dataclass
class DataPipelineConfig:
    source_path: str
    output_path: str
    batch_size: int = 1000
    max_workers: int = 4
    timeout_seconds: int = 300
    retry_attempts: int = 3
    compression: Optional[str] = None
    validation_rules: dict[str, str] = field(default_factory=dict)
    
    def __post_init__(self):
        if self.compression and self.compression not in ("gzip", "lz4", "snappy"):
            raise ValueError(f"Unsupported compression: {self.compression}")
        
        # Default validation rules
        if not self.validation_rules:
            self.validation_rules = {
                "not_null": "all_columns",
                "unique": "id_column",
            }

# Usage
config = DataPipelineConfig(
    source_path="s3://data/raw/",
    output_path="s3://data/processed/",
    batch_size=5000,
    compression="gzip"
)
```

### Experiment Tracking

```python
from dataclasses import dataclass, field, asdict
from datetime import datetime
import json

@dataclass
class Experiment:
    name: str
    description: str
    config: dict
    created_at: str = field(default_factory=lambda: datetime.now().isoformat())
    status: str = "created"
    metrics: dict = field(default_factory=dict)
    tags: list[str] = field(default_factory=list)
    
    def log_metric(self, name: str, value: float):
        if name not in self.metrics:
            self.metrics[name] = []
        self.metrics[name].append(value)
    
    def save(self, path: str):
        with open(path, "w") as f:
            json.dump(asdict(self), f, indent=2)

# Usage
exp = Experiment(
    name="resnet50_v2",
    description="Fine-tuning ResNet50 on custom dataset",
    config={"lr": 0.001, "epochs": 50, "batch_size": 16}
)

exp.log_metric("accuracy", 0.85)
exp.log_metric("loss", 0.35)
exp.save("experiments/resnet50_v2.json")
```

## 10. Best Practices

1. **Use `default_factory`** for mutable defaults (lists, dicts, sets)
2. **Keep dataclasses focused** — one responsibility per class
3. **Use `__post_init__`** for validation and derived values
4. **Consider `frozen=True`** for data that shouldn't change
5. **Use `field(init=False)`** for computed attributes
6. **Prefer dataclasses** over dicts for structured data
7. **Use `asdict()`** for serialization
8. **Document fields** with type hints and comments
9. **Test validation** in `__post_init__`
10. **Consider slots=True** (Python 3.10+) for memory efficiency

## 12. Summary

| Concept | Description |
|---------|-------------|
| **`@dataclass`** | Decorator that auto-generates methods |
| **`field()`** | Configure individual fields |
| **`default_factory`** | Factory function for mutable defaults |
| **`frozen=True`** | Immutable dataclass (hashable) |
| **`__post_init__`** | Post-initialization validation |
| **`asdict()`** | Convert to dictionary recursively |
| **`astuple()`** | Convert to tuple |
| **`fields()`** | Access field metadata |
| **Inheritance** | Dataclasses support inheritance |
| **Slots** | Python 3.10+ memory optimization |

Dataclasses are a cornerstone of modern Python development, providing clean, type-safe data structures with minimal boilerplate. They're essential for AI engineering workflows where configuration, data models, and API responses need to be well-defined and maintainable.
