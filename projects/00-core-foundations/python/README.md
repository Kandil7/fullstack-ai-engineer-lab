## 🚀 How to Run

### Prerequisites
- Python 3.6+ installed (3.10+ for `18-match.py`)
- Verify with: `python --version`

### Running a Single Exercise
```bash
python 01-introduction.py
```

### Running All Exercises
```bash
# Windows PowerShell
Get-ChildItem *.py | ForEach-Object { python $_.Name; Write-Host "`n---`n" }

# Linux/Mac
for f in *.py; do python "$f"; echo "---"; done
```

### Running from VS Code
1. Open any `.py` file
2. Click the "Run" button (▶️) or press `F5`

## 🔧 Troubleshooting

### Common Issues

**`python` not recognized**
```bash
# Try python3 instead
python3 01-introduction.py
```

**Syntax error on `match` statement**
- Requires Python 3.10 or newer
- Check version: `python --version`

**Permission errors**
- Make sure you have write permissions in the directory
- Run terminal as administrator if needed
