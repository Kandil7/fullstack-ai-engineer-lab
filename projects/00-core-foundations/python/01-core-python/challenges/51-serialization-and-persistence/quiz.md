# Challenge 51 — Quiz: Serialization & Persistence

1. JSON cannot natively represent:
   - A) dicts  (B) sets and tuples  (C) lists  (D) booleans
2. `object_hook` is used to:
   - A) speed up parsing  (B) transform decoded dicts  (C) validate types  (D) compress
3. The dataset format of fine-tuning is typically:
   - A) XML  (B) JSONL  (C) YAML  (D) INI
4. Unpickling untrusted data is dangerous because:
   - A) it is slow  (B) it can execute arbitrary code  (C) it corrupts memory  (D) it loses types
5. SQL injection happens when:
   - A) values are passed as parameters  (B) values are interpolated into SQL text  (C) queries are long  (D) tables are indexed
6. Correct parameter usage is:
   - A) `WHERE x = ?`, `(v,)`  (B) `f"WHERE x = {v}"`  (C) `WHERE x = %s`  (D) `WHERE x = :v` only
7. Opening CSV files with `newline=''`:
   - A) is optional  (B) prevents doubled `\r\n` on Windows  (C) breaks Linux  (D) adds quoting
8. `ensure_ascii=False`:
   - A) disables escaping  (B) keeps non-ASCII readable  (C) is deprecated  (D) speeds up dumps

**Answers:** 1-B, 2-B, 3-B, 4-B, 5-B, 6-A, 7-B, 8-B
