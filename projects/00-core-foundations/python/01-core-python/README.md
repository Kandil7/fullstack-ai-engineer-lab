# 📘 Phase 1: Core Python Fundamentals

43 exercise files covering Python from absolute basics through object-oriented programming and file handling.

## Contents

| Range | Topic Area | Files |
|-------|-----------|-------|
| 01–06 | Introduction, Setup, Syntax, Output, Comments, Variables |
| 07–11 | Data Types, Numbers, Casting, Strings, Booleans |
| 12–16 | Operators, Lists, Tuples, Sets, Dictionaries |
| 17–20 | If/Else, Match, While/For Loops |
| 21–24 | Functions, Range, Arrays, Iterators |
| 25–29 | Modules, Dates, Math, JSON, RegEx |
| 30–33 | Try/Except, String Formatting, None, User Input |
| 34–37 | Classes, Inheritance, Polymorphism, Encapsulation |
| 38–41 | File Handling, PIP, VirtualEnv, Inner Classes |

**Also includes:** `practice_all.py` (99 problems with solutions) and `practice_no_solutions.py` (blank stubs).

## Quick Start

```bash
# Run any file
python 01-introduction.py

# Run all files sequentially
python ../run_smoke_tests.py --phase 1
```
