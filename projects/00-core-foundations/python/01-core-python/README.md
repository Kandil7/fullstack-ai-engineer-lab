# 📘 Phase 1: Core Python Fundamentals

88 Python files including 52 numbered exercise files (01–52), 2 practice files, and lecture/glossary/challenge files covering Python from absolute basics through advanced topics like memory optimization, serialization, and datetime handling.

## Contents

| Range | Topic Area | Files |
|-------|-----------|-------|
| 01–06 | Introduction, Setup, Syntax, Output, Comments, Variables | 01–06 |
| 07–11 | Data Types, Numbers, Casting, Strings, Booleans | 07–11 |
| 12–16 | Operators, Lists, Tuples, Sets, Dictionaries | 12–16 |
| 17–20 | If/Else, Match, While/For Loops | 17–20 |
| 21–24 | Functions, Range, Arrays, Iterators | 21–24 |
| 25–29 | Modules, Dates, Math, JSON, RegEx | 25–29 |
| 30–33 | Try/Except, String Formatting, None, User Input | 30–33 |
| 34–37 | Classes, Inheritance, Polymorphism, Encapsulation | 34–37 |
| 38–41 | File Handling, PIP, VirtualEnv, Inner Classes | 38–41 |

Lectures and glossaries for every topic live in [`lectures/`](lectures/).

**Also includes:** `practice_all.py` (99 problems with solutions) and `practice_no_solutions.py` (blank stubs).

## Quick Start

```bash
# Run any file
python 01-introduction.py

# Run all files sequentially
python ../run_smoke_tests.py --phase 1
```
