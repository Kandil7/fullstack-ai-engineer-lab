# 📊 Project 04: Data Analyzer

A comprehensive data analysis tool that generates synthetic customer data, performs statistical analysis, and creates visualization reports.

## What This Project Practices

| Skill | Phase | Details |
|-------|-------|---------|
| Pandas | Phase 3 | DataFrames, groupby, describe, correlations |
| NumPy | Phase 3 | Random generation, statistics, masking |
| Matplotlib | Phase 3 | Histograms, scatter, bar charts, heatmaps |
| Data Cleaning | Phase 3 | Missing values, outlier detection |
| Statistics | Phase 3 | Mean, median, IQR, correlation |
| File Output | Phase 1 | Text reports, image saving |
| Error Handling | Phase 1 | NaN handling |

## How to Run

```bash
python projects/04-data-analyzer/main.py
```

## Output

All output is saved to `projects/04-data-analyzer/output/`:
- `analysis_report.txt` — Full text report
- `01_income_distribution.png` — Income histogram
- `02_spending_vs_income.png` — Scatter plot with color mapping
- `03_region_metrics.png` — Regional bar charts
- `04_correlation_matrix.png` — Annotated heatmap
- `05_membership_duration.png` — Customer tenure histogram
