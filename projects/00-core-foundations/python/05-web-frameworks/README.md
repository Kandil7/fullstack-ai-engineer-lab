# 🌐 Phase 5: Web Frameworks

45 reference/lesson files covering FastAPI (runnable) and Django (reference).

| Framework | Files | Style |
|-----------|-------|-------|
| **FastAPI** | 25 files + exercises + lectures | Runnable scripts with `uvicorn` |
| **Django** | 20 files | Reference guides with code snippets |

## Quick Start (FastAPI)

```bash
# Install dependencies
pip install fastapi uvicorn

# Run any FastAPI file
cd fastapi
uvicorn 01-introduction:app --reload

# Open docs
# http://127.0.0.1:8000/docs
```

## Quick Start (Django)

```bash
# Install Django
pip install django

# Reference guides are in django/*.py
# See django/01-introduction.py for setup instructions
```
