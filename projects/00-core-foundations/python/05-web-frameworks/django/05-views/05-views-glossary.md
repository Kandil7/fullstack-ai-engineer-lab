## Related Concepts

- **MVT**: Model (data), View (logic), Template (presentation)
- **DRY**: Don't Repeat Yourself - reuse components
- **Convention over Configuration**: Django's naming conventions

## Key Takeaways

1. Django follows the "convention over configuration" philosophy
2. Each app should be a self-contained module
3. Django's ORM abstracts database complexity
4. Use Django's built-in admin for rapid prototyping
