## Detailed Definitions
### Argument
**Definition**: A typed parameter value generated by the model for a tool.
**Related**: Tool Call

### Function Calling
**Definition**: The protocol where the model returns structured tool
invocations.
**Related**: Tool Call

### Loop Budget
**Definition**: The cap on turns, calls, and tokens in a single agent run.
**Related**: Tool Message

### Side Effect
**Definition**: A tool action with real-world consequences (sending email,
mutating data).
**Related**: Whitelist

### Tool
**Definition**: A declared capability with a name, description, and schema.
**Related**: Tool Call

### Tool Call
**Definition**: The model's typed request: tool name + arguments.
**Related**: Argument

### Tool Message
**Definition**: The execution result returned to the model as a message.
**Related**: Function Calling

### Whitelist
**Definition**: The explicit allow-list of operations a tool may perform.
**Related**: Side Effect

## Key Concepts Summary
### The Loop
- Declare → call → validate → execute → feed back

### The Rules
- Validate model arguments
- Budget every loop
- Whitelist side effects
