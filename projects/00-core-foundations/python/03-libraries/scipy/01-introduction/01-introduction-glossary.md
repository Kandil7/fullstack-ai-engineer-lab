# SciPy Lecture 01: Introduction — Glossary

| Term | Definition | Example |
|------|-----------|---------|
| SciPy | Scientific Python library for advanced computing | `from scipy import optimize` |
| Module | Self-contained subpackage within SciPy | `scipy.stats`, `scipy.linalg` |
| Optimization | Finding minima/maxima of functions | `scipy.optimize.minimize()` |
| Integration | Computing definite integrals | `scipy.integrate.quad()` |
| Interpolation | Estimating values between known points | `scipy.interpolate.interp1d()` |
| Statistics | Probability distributions and tests | `scipy.stats.ttest_ind()` |
| Sparse Matrix | Matrix with mostly zero entries | `scipy.sparse.csr_matrix()` |
| FFT | Fast Fourier Transform | `scipy.fft.fft()` |
| Signal Processing | Analyzing/modifying signals | `scipy.signal.convolve()` |
| ndimage | N-dimensional image processing | `scipy.ndimage.gaussian_filter()` |
| KD-Tree | Spatial indexing structure | `scipy.spatial.KDTree()` |
| B-Spline | Basis spline for interpolation | `scipy.interpolate.splrep()` |
