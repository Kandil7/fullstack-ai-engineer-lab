# SciPy Lecture 02: Getting Started — Glossary

| Term | Definition | Example |
|------|-----------|---------|
| Submodule | Self-contained package within SciPy | `scipy.optimize`, `scipy.stats` |
| Constants | Physical and mathematical constants | `scipy.constants.c` |
| Special Functions | Advanced mathematical functions | `scipy.special.gamma()` |
| Bessel Functions | Solutions to Bessel's differential equation | `special.jv(0, x)` |
| Gamma Function | Extension of factorial to real numbers | `special.gamma(5) = 24` |
| Error Function | Integral of the Gaussian distribution | `special.erf(x)` |
| Combinatorial | Counting combinations and permutations | `special.comb(10, 3)` |
| `const.c` | Speed of light (299,792,458 m/s) | `constants.c` |
| `const.h` | Planck constant (6.626×10⁻³⁴ J·s) | `constants.h` |
| `const.G` | Gravitational constant (6.674×10⁻¹¹) | `constants.G` |
| `const.N_A` | Avogadro number (6.022×10²³) | `constants.N_A` |
| `const.k` | Boltzmann constant (1.381×10⁻²³ J/K) | `constants.k` |
