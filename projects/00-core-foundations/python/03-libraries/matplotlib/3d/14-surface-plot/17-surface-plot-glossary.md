# Matplotlib Lecture 17: 3D Surface Plots — Glossary

## Quick Reference

| Term | Definition | Example |
|------|-----------|---------|
| Surface Plot | 3D shaded surface | `ax.plot_surface(X, Y, Z)` |
| Shade | Lighting simulation | `shade=True` |
| Antialiased | Smooth edges | `antialiased=True` |
| Facecolor | Surface face color | `facecolor='steelblue'` |
| Contour Projection | 2D contours on 3D axes | `ax.contour(X, Y, Z, zdir='z')` |

## Glossary

### A

**Antialiased** — A rendering technique that smooths jagged edges in 3D plots.

### C

**Contour Projection** — Contour lines drawn on the walls of a 3D plot (xz, yz, or xy planes).

### S

**Shade** — Simulates lighting on a 3D surface by varying face colors based on surface normal direction.

**Surface Plot** — A 3D plot showing a continuous function as a colored, shaded surface.
