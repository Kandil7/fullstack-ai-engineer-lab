# Matplotlib Lecture 18: 3D Scatter Plots — Glossary

## Quick Reference

| Term | Definition | Example |
|------|-----------|---------|
| 3D Scatter | Points in 3D space | `ax.scatter3D(x, y, z)` |
| 3D Axes | Axes with depth | `projection='3d'` |
| Depth Encoding | 3D visual perception | Perspective + occlusion |
| Rotation | View angle animation | `view_init(elev, azim)` |

## Glossary

### 3

**3D Axes** — Axes with an additional z-axis for 3D visualization, created with `projection='3d'`.

**3D Scatter** — A scatter plot with three spatial dimensions (x, y, z), revealing 3D patterns.

### D

**Depth Encoding** — Visual cues in 3D plots that convey the z-dimension through perspective, occlusion, and size.

### R

**Rotation** — Changing the viewing angle over time, often animated, to reveal 3D structure.
