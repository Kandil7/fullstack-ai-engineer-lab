# Matplotlib Lecture 19: 3D Line Plots — Glossary

## Quick Reference

| Term | Definition | Example |
|------|-----------|---------|
| 3D Line | Path in 3D space | `ax.plot3D(x, y, z)` |
| Parametric Curve | (x,y,z) from parameter t | `(cos(t), sin(t), t)` |
| Helix | Spiral 3D curve | `(cos(t), sin(t), t/10)` |
| Lissajous Curve | Frequency-based 3D | `(sin(at), sin(bt), sin(ct))` |
| Trajectory | Path over time | `ax.plot(x, y, z)` |

## Glossary

### H

**Helix** — A 3D spiral curve where the radius is constant while the z-coordinate increases linearly.

### L

**Lissajous Curve** — A parametric curve where each coordinate follows a sinusoidal function with different frequencies.

### P

**Parametric Curve** — A curve in 3D space defined by three functions of a single parameter t: (x(t), y(t), z(t)).

### T

**Trajectory** — The path of a point moving through 3D space, often representing position over time.
