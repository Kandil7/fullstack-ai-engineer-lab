# Matplotlib Lecture 09: Scatter Plots — Glossary

## Quick Reference

| Term | Definition | Example |
|------|-----------|---------|
| Scatter Plot | Points showing two variables | `plt.scatter(x, y)` |
| Colorbar | Color-value mapping legend | `plt.colorbar()` |
| Colormap | Color palette for values | `cmap='viridis'` |
| Marker Size | Point area in points² | `s=50` |
| Alpha | Point transparency | `alpha=0.7` |
| Edge Color | Point border color | `edgecolors='black'` |
| Bubble Chart | Scatter with size encoding | `s=third_variable` |

## Glossary

### B

**Bubble Chart** — A scatter plot where marker size encodes a third numerical variable.

### C

**Colorbar** — A legend that maps numerical values to colors, showing the colormap scale.

**Colormap** — A color palette mapping data values to colors (viridis, plasma, coolwarm, RdBu, etc.).

### S

**Scatter Plot** — A plot using Cartesian coordinates to display values for typically two variables.
