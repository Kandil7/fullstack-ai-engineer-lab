# Matplotlib Lecture 04: Markers — Glossary

## Quick Reference

| Term | Definition | Example |
|------|-----------|---------|
| Marker | Symbol at data points | `marker='o'` |
| Marker Size | Size of marker in points | `markersize=10` |
| Marker Face Color | Fill color of marker | `markerfacecolor='white'` |
| Marker Edge Color | Border color of marker | `markeredgecolor='black'` |
| Marker Edge Width | Width of marker border | `markeredgewidth=2` |
| `markevery` | Show every Nth marker | `markevery=5` |
| Point Marker | Small dot | `'.'` |
| Circle Marker | Circle shape | `'o'` |
| Square Marker | Square shape | `'s'` |
| Diamond Marker | Diamond shape | `'D'` |
| Star Marker | Star shape | `'*'` |

## Glossary

### M

**markevery** — Controls which data points show markers. Can be int (every Nth), list (specific indices), slice, or float (fraction of data).

**Marker** — A visual symbol placed at each data point location on a plot.

**Marker Edge Color** — The color of the outline/border of a marker symbol.

**Marker Edge Width** — The thickness of the outline/border of a marker symbol.

**Marker Face Color** — The fill color inside a marker symbol.

**Marker Size** — The size of the marker, measured in points (1 point = 1/72 inch).
