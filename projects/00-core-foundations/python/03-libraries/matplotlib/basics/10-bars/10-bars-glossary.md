# Matplotlib Lecture 10: Bar Charts — Glossary

## Quick Reference

| Term | Definition | Example |
|------|-----------|---------|
| Bar Chart | Categorical comparison | `plt.bar(x, height)` |
| Horizontal Bar | Horizontal bars | `plt.barh(y, width)` |
| Stacked Bar | Bars stacked on each other | `bottom=previous_values` |
| Grouped Bar | Side-by-side bars | `x + width` offset |
| Error Bar | Uncertainty visualization | `yerr=errors` |
| `barh()` | Horizontal bar chart | `plt.barh(categories, values)` |

## Glossary

### B

**Bar Chart** — A chart with rectangular bars showing categorical data comparison.

**barh()** — Horizontal bar chart function where bars extend horizontally from the y-axis.

### E

**Error Bar** — Lines extending from bar tops showing measurement uncertainty or variability.

### G

**Grouped Bar** — Multiple bars for each category placed side-by-side for comparison.

### S

**Stacked Bar** — Multiple data series stacked on top of each other in a single bar per category.
