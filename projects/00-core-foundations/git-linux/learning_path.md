# 🗺️ Git & Linux Learning Path

> **2-week plan** — Week 1 focuses on Git, Week 2 on Linux and shell scripting.

---

## 🗓️ Week 1: Git

| Day | Topic | Practice |
|-----|-------|----------|
| 1 | Git basics | `init`, `add`, `commit`, `status`, `log`, `diff` |
| 2 | Branching | `branch`, `checkout`, `merge`, `branch -d` |
| 3 | Remote repos | `clone`, `push`, `pull`, `fetch`, `remote` |
| 4 | Rebasing | `rebase`, interactive rebase, `rebase --onto` |
| 5 | Merge conflicts | Create a conflict, resolve with `merge` and `rebase` |
| 6 | Advanced | `stash`, `cherry-pick`, `bisect`, `reset`, `reflog` |
| 7 | Git hooks | Write a pre-commit hook (lint check), pre-push hook (test) |

## 🗓️ Week 2: Linux & Shell

| Day | Topic | Practice |
|-----|-------|----------|
| 8 | File system | `ls`, `cd`, `find`, `locate`, `tree`, file globbing |
| 9 | File operations | `cp`, `mv`, `rm`, `ln`, `chmod`, `chown`, `umask` |
| 10 | Text processing | `grep`, `sed`, `awk`, `cut`, `sort`, `uniq`, `wc` |
| 11 | Process management | `ps`, `top`, `kill`, `nohup`, `screen`/`tmux` |
| 12 | Bash scripting | Variables, `if`, `for`, `while`, `case`, functions |
| 13 | Pipes & redirection | `|`, `>`, `>>`, `<`, `2>&1`, `tee`, `xargs` |
| 14 | SSH & cron | Keys, `ssh-config`, tunnels, `rsync`, `crontab` |

---

## ✅ Self-Assessment

After completing this module, you should be able to:

- [ ] Create a Git repo, commit changes, push to remote
- [ ] Create and merge branches, resolve conflicts
- [ ] Use interactive rebase to clean up commit history
- [ ] Use `git bisect` to find a bug-introducing commit
- [ ] Write a pre-commit Git hook
- [ ] Navigate the Linux file system efficiently
- [ ] Use `grep`, `sed`, and `awk` for text processing
- [ ] Write a bash script with functions and error handling
- [ ] Set up SSH key-based authentication
- [ ] Schedule tasks with cron
