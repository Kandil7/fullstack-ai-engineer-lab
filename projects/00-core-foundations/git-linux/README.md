# 🐧 Git & Linux — Core Foundations

> **Practical guide to Git workflows, Linux fundamentals, and shell scripting.** Every DevOps, CI/CD, and deployment task runs on Linux with Git.

---

## 📋 Overview

| Module | Topics | Why It Matters |
|--------|--------|----------------|
| **Git** | Branching, rebasing, merging, bisect, hooks | Every team uses Git for collaboration |
| **Linux** | File system, permissions, processes, networking | All servers run Linux |
| **Shell Scripting** | Bash, pipes, redirection, automation | Automate everything |
| **SSH & Remote** | Key management, tunneling, rsync | Access remote servers securely |

---

## 🎯 Learning Objectives

After completing this module, you'll be able to:

- **Git**: Navigate branches, resolve merge conflicts, rebase interactively, bisect bugs, write hooks
- **Linux**: Manage files/processes/users, set permissions, monitor system resources, use pipes
- **Shell**: Write bash scripts with variables, conditionals, loops, functions, error handling
- **SSH**: Set up key-based auth, create tunnels, sync with rsync

## ✅ Progress Checklist

- [ ] Git basics: init, add, commit, log, diff
- [ ] Branching: create, merge, rebase, resolve conflicts
- [ ] Interactive rebase: squash, reword, reorder
- [ ] git bisect: find the commit that introduced a bug
- [ ] Git hooks: pre-commit, pre-push
- [ ] Linux file system: ls, cd, find, locate
- [ ] File permissions: chmod, chown, umask
- [ ] Process management: ps, top, kill, nohup
- [ ] Text processing: grep, sed, awk, cut, sort, uniq
- [ ] Bash scripting: variables, conditionals, loops, functions
- [ ] SSH: keys, config, tunnels, rsync
- [ ] Cron jobs: schedule tasks
- [ ] Networking: curl, netstat, ping, ss
