# 🗺️ DS & Algo Learning Path

> **3-week plan** — 5 exercises per week, building from basic to advanced.

---

## 🗓️ Week 1: Foundations

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 1 | Big-O Analysis | O(1), O(n), O(n²), O(log n), O(2ⁿ) |
| 2 | Arrays & Strings | Contiguous memory, two-pointer technique |
| 3 | Linked Lists | Node-based, pointer manipulation |
| 4 | Stacks | LIFO, expression parsing, bracket matching |
| 5 | Queues | FIFO, circular buffer, deque |

## 🗓️ Week 2: Intermediate

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 6 | Hash Tables | O(1) lookup, collision resolution |
| 7 | Binary Search | Divide & conquer, rotated arrays |
| 8 | Sorting | Comparison-based, O(n log n) |
| 9 | Trees | Recursive structures, traversals |
| 10 | Heaps | Priority queues, heap property |

## 🗓️ Week 3: Advanced

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 11 | Graphs | Adjacency lists, representations |
| 12 | Graph Algorithms | BFS, DFS, shortest paths |
| 13 | Dynamic Programming | Optimal substructure, overlapping subproblems |
| 14 | Greedy Algorithms | Local optimum → global optimum |
| 15 | Tries | Prefix trees, string search |

---

## ✅ Self-Assessment

After completing all exercises, you should be able to:

- [ ] Analyze time and space complexity of any algorithm
- [ ] Choose the right data structure for a given problem
- [ ] Implement all core data structures from scratch
- [ ] Apply BFS/DFS to graph problems
- [ ] Recognize DP subproblem patterns
- [ ] Solve medium LeetCode problems independently
