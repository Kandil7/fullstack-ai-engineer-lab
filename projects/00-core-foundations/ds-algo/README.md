# ⚙️ Data Structures & Algorithms

> **15 progressive exercises** covering all core DSA topics with Go implementations.

---

## 🎯 Overview

Data structures and algorithms are the foundation of efficient code. This module covers the essential structures and algorithms every engineer needs, with a focus on problems that appear in AI system design (caching, scheduling, search, graph traversal).
