# AI Security Quizzes

A comprehensive collection of multiple-choice quizzes covering essential AI security topics. These quizzes help you test and reinforce your knowledge of securing AI systems, from prompt injection defenses to infrastructure security.

## What This Directory Contains

This directory includes **10 specialized quizzes** covering the full spectrum of AI security topics. Each quiz contains:

- **Topic overview** with key concepts
- **18 multiple-choice questions** (Easy/Medium/Hard difficulty)
- **Detailed explanations** for each answer
- **Score tracking** table
- **Answer key** for quick reference

## How to Use These Quizzes

### Self-Assessment
1. Open a quiz file in your preferred editor or markdown viewer
2. Read the topic overview to refresh your knowledge
3. Answer each question without looking at the answer
4. Check your answers against the answer key at the end
5. Review explanations for any questions you got wrong

### Study Group
1. Take turns asking questions from the quiz
2. Discuss why certain answers are correct or incorrect
3. Share real-world examples related to each topic
4. Challenge each other with the Hard difficulty questions

### Interview Preparation
1. Work through quizzes covering topics relevant to your target role
2. Practice explaining why each answer is correct
3. Time yourself to simulate interview conditions
4. Focus on Hard questions for senior-level positions

## Difficulty Levels

- **Easy** — Foundational concepts, basic terminology, clear definitions
- **Medium** — Applied knowledge, understanding trade-offs, practical scenarios
- **Hard** — Advanced concepts, nuanced understanding, complex attack scenarios
