# AI Security Quiz: Security Monitoring

## Topic Overview

Security monitoring for AI systems involves detecting, analyzing, and responding to threats across the AI pipeline. This quiz covers logging, anomaly detection, incident response, and operational security practices for maintaining AI system integrity.

### Key Concepts
- Security logging and auditing
- Anomaly detection in AI systems
- Incident response procedures
- Threat intelligence
- Security metrics and alerting

---

## Quiz

### Question 1 — Easy
**Why is security monitoring essential for AI systems?**

- A) It improves model accuracy
- B) It detects and responds to security threats in real-time
- C) It reduces infrastructure costs
- D) It's only required for compliance

**Answer: B**

**Explanation:** Security monitoring provides visibility into system behavior, enabling detection of attacks, anomalies, and policy violations before they cause significant damage.

---

### Question 2 — Easy
**What is "audit logging" in AI security?**

- A) Logging model training progress
- B) Recording all system actions for security review and compliance
- C) Logging user feedback
- D) Recording network speed

**Answer: B**

**Explanation:** Audit logging records all significant system actions, providing a trail for security investigations, compliance requirements, and forensic analysis.

---

### Question 3 — Easy
**What is an "alert threshold" in monitoring?**

- A) The maximum number of alerts allowed
- B) The value at which a monitoring system triggers an alert
- C) The minimum log level
- D) The number of servers to monitor

**Answer: B**

**Explanation:** Alert thresholds define the conditions (e.g., error rate > 5%, latency > 2s) that trigger notifications, helping teams respond to issues while avoiding alert fatigue.

---

### Question 4 — Medium
**What is "anomaly detection" in AI security monitoring?**

- A) Finding errors in code
- B) Identifying unusual patterns that deviate from normal behavior
- C) Detecting hardware failures
- D) Finding syntax errors

**Answer: B**

**Explanation:** Anomaly detection identifies patterns that deviate from established baselines, potentially indicating attacks, system failures, or policy violations.

---

### Question 5 — Medium
**What is a "SIEM" system?**

- A) A type of AI model
- B) Security Information and Event Management for centralized log analysis
- C) A database management system
- D) A network protocol

**Answer: B**

**Explanation:** SIEM systems aggregate and analyze log data from multiple sources, providing centralized visibility, correlation of events, and security alerting capabilities.

---

### Question 6 — Medium
**What is the purpose of "distributed tracing" in AI systems?**

- A) Tracing physical wires
- B) Tracking requests across distributed components to identify issues and attacks
- C) Tracing user mouse movements
- D) Tracking network cables

**Answer: B**

**Explanation:** Distributed tracing follows requests through multiple services and components, helping identify bottlenecks, errors, and suspicious activity across the AI pipeline.

---

### Question 7 — Medium
**What is "alert fatigue" in security monitoring?**

- A) Physical fatigue from monitoring
- B) Desensitization to alerts due to excessive false positives
- C) System fatigue from too many logs
- D) Network fatigue from traffic

**Answer: B**

**Explanation:** Alert fatigue occurs when teams receive too many false or low-priority alerts, causing them to potentially miss critical security notifications.

---

### Question 8 — Medium
**What is "log correlation" in security monitoring?**

- A) Logging related information
- B) Connecting related events across multiple log sources to identify attack patterns
- C) Sorting logs alphabetically
- D) Compressing log files

**Answer: B**

**Explanation:** Log correlation connects related events from different systems and time periods, helping identify complex attack patterns that span multiple components.

---

### Question 9 — Hard
**What is a "security incident response plan" for AI systems?**

- A) A plan to prevent all incidents
- B) Documented procedures for detecting, containing, and recovering from security incidents
- C) A plan to increase incidents
- D) A plan for daily operations

**Answer: B**

**Explanation:** An incident response plan provides structured procedures for handling security incidents, including detection, containment, eradication, recovery, and lessons learned.

---

### Question 10 — Hard
**What is "threat modeling" for AI systems?**

- A) Building physical threat models
- B) Systematically identifying and evaluating potential security threats
- C) Creating user threat scenarios
- D) Modeling weather threats

**Answer: B**

**Explanation:** Threat modeling systematically identifies potential threats, vulnerabilities, and attack vectors specific to the AI system, helping prioritize security investments and defenses.

---

### Question 11 — Hard
**What is "behavioral analytics" in AI security monitoring?**

- A) Analyzing user behavior on social media
- B) Using ML to detect anomalous user or system behavior patterns
- C) Analyzing model behavior only
- D) Monitoring physical behavior

**Answer: B**

**Explanation:** Behavioral analytics uses machine learning to establish behavioral baselines and detect deviations that may indicate compromised accounts, insider threats, or attack activity.

---

### Question 12 — Hard
**What is "purple teaming" in AI security?**

- A) A team wearing purple uniforms
- B) Collaborative exercise where red (attack) and blue (defense) teams work together
- C) A third-party audit team
- D) A management team

**Answer: B**

**Explanation:** Purple teaming combines offensive (red) and defensive (blue) security teams in collaborative exercises, improving both attack detection and defense capabilities through shared learning.

---

### Question 13 — Easy
**What is "log retention" in security?**

- A) Keeping logs forever
- B) Defining how long security logs are stored before deletion
- C) Retaining only error logs
- D) Storing logs in memory only

**Answer: B**

**Explanation:** Log retention policies define how long logs are kept based on compliance requirements, investigation needs, and storage constraints, balancing security needs with practical limitations.

---

### Question 14 — Medium
**What is a "security dashboard" used for?**

- A) Displaying weather information
- B) Providing real-time visibility into security metrics and alerts
- C) Managing user accounts only
- D) Displaying model performance only

**Answer: B**

**Explanation:** Security dashboards aggregate key security metrics, alerts, and status indicators into a single view, enabling rapid assessment of security posture and incident status.

---

### Question 15 — Medium
**What is "mean time to detect" (MTTD)?**

- A) Time to detect hardware failures
- B) Average time taken to identify a security incident
- C) Time to train a model
- D) Time to deploy code

**Answer: B**

**Explanation:** MTTD measures how quickly security teams identify incidents, with lower values indicating more effective monitoring and detection capabilities.

---

### Question 16 — Easy
**What is "security information" in monitoring?**

- A) Classified information
- B) Data about security events, threats, and system vulnerabilities
- C) User personal information
- D) Marketing information

**Answer: B**

**Explanation:** Security information includes data about threats, vulnerabilities, security events, and system status that helps teams understand and protect the AI system.

---

### Question 17 — Hard
**What is "deception technology" in AI security monitoring?**

- A) Deceiving users about security
- B) Using decoys and honeypots to detect and analyze attacker behavior
- C) Hiding security logs
- D) Disguising network traffic

**Answer: B**

**Explanation:** Deception technology deploys decoys (honeypots, honeytokens) that appear as legitimate targets, detecting attackers early while gathering intelligence about their methods.

---

### Question 18 — Medium
**What is the purpose of "security metrics"?**

- A) Measuring model accuracy
- B) Quantifying security posture and measuring effectiveness of security controls
- C) Counting user sessions
- D) Measuring response latency only

**Answer: B**

**Explanation:** Security metrics provide quantitative measures of security effectiveness, helping teams assess their security posture, justify investments, and identify areas for improvement.
