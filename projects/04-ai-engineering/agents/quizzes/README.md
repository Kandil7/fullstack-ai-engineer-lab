## How to Use These Quizzes

### Self-Assessment
1. Open a quiz file and read each question
2. Select your answer (A, B, C, or D) before revealing the answer
3. Click "Reveal Answer" to check your choice
4. Read the explanation to understand why the answer is correct
5. Track your score using the Score Tracker table

### Study Strategy
1. **Start with Quiz 01** (Agent Fundamentals) to establish a baseline
2. **Take quizzes in order** — each builds on concepts from previous quizzes
3. **Review explanations** even for questions you get right — deepen understanding
4. **Retake quizzes** after studying the topic to measure improvement
5. **Focus on weak areas** — use the scoring guide to identify topics to study

### Group Study
1. Use quizzes as discussion starters in study groups
2. Have each person take the quiz independently, then discuss answers
3. Debate the explanations — understanding *why* matters more than memorizing answers
4. Create additional questions based on the topics covered
