# AI Automation Practice Problems

**135 problems across 9 modules. No solutions. No hints.**

Every function body is `pass` — you must figure it out yourself.

## How to Use

1. Pick a module based on where you are in the curriculum
2. Open the practice file
3. Run it to see the problem list: `python 01-llm-api-integration-practice.py`
4. Pick a problem, read its docstring, and implement the function
5. Test your implementation against real APIs
6. Move to the next problem

Each module has:
- **Easy (20 XP):** Problems 1-5 — basic concepts, single function

- **Hard (100 XP):** Problems 11-15 — complete systems, production patterns
