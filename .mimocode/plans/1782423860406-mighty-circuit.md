## Learning Path Options

### Option A: Start with Prompt Engineering (quickest win)
1. Create `projects/04-ai-engineering/prompt-engineering/` with Python scripts
2. Build prompt templates, few-shot examples, chain-of-thought demos
3. Use `.ai/prompts/` system as reference (21 existing prompts)
4. Evaluate with `prompt-regression.md` workflow

### Option B: Build RAG Pipeline (core AI skill)
1. Set up Qdrant locally (already in Docker Compose)
2. Create chunking, embedding, retrieval, generation code
3. Use `rag-quality-check.md` workflow for evaluation
4. Build on FastAPI (already learned in Phase 0)

### Option C: Follow 12-Month Plan Phase 4 (months 10-12)
1. Month 10: Python for AI + LLMs (ML for Beginners, Karpathy)
2. Month 11: Transformers + RAG (HF course, DeepLearning.AI)
3. Month 12: Agents + Capstone (CrewAI, HF Agents)

### Option D: Build Agent System (most ambitious)
1. Implement ReAct loop with tool calling
2. Build multi-agent orchestration
3. Add memory store (Redis-backed)
4. Use existing prompt system as agent definitions

## Recommended Approach

**Start with Option A (Prompt Engineering) as a warm-up, then move to Option B (RAG Pipeline).**

Rationale:
- Prompt engineering builds on the 21 existing prompts — immediate hands-on practice
- RAG pipeline uses Qdrant (already in Docker) and FastAPI (already learned)
- Both produce portfolio-ready projects
- Agents (Option D) build naturally on RAG + prompt engineering skills
